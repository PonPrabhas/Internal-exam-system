# Internal Examination System

This is a Django-based web application for managing internal exams in educational institutions. It includes modules for admin (HOD), teachers, and students, supporting features like syllabus upload, question paper generation, online exams, and malpractice prevention.

## Features
- Role-based login for Admin, Teacher, and Student
- Course & syllabus management
- Random question selection based on pattern (MCQ & Subjective)
- Subjective answer storage & teacher evaluation
- Automated MCQ evaluation
- Tab switch detection, copy-paste block, timer, and screenshot block
- Academic calendar with internal exam dates

## Technologies
- Backend: Django (Python)
- Frontend: HTML, CSS, Bootstrap
- Database: SQLite
